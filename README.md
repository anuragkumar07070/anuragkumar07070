## 🛠️ Featured projects

### [🚢 CloudShip](https://github.com/anuragkumar07070/cloudship): self-hosted deployment platform
Paste a GitHub URL and get running Docker containers on a live URL, no Dockerfile required. It scans the repo, classifies services, generates Dockerfiles, builds and runs containers on isolated networks behind an Nginx reverse proxy, health-checks them, and cleans up everything on failure. The AWS EC2 host is provisioned with **Terraform**.

`Node.js` `Docker` `Nginx` `Terraform` `AWS EC2` `SQLite` `React`

### 🍽️ QuickDine: QR-based restaurant ordering
Customers scan a table QR code, order, pay with **Razorpay** and track the order live. Frontend on **S3 + CloudFront**, backend on **Lambda + API Gateway**, all defined in a **CloudFormation** template. JWT auth with role-based access control and real-time updates over Socket.IO.

`React` `Node.js` `MongoDB` `Socket.IO` `AWS Lambda` `CloudFormation`

### 🏨 [RoundWorld](https://github.com/anuragkumar07070/RoundWorld): accommodation booking platform
Full-stack hotel and vacation rental platform.

`JavaScript` `Node.js` `Express` `MongoDB`
